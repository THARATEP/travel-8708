# ระบบเบิกค่าใช้จ่ายในการเดินทางไปราชการ (ส.ป.ก.)

เว็บแอปไฟล์เดียว (Single-file HTML) สำหรับจัดทำเอกสารเบิกค่าใช้จ่ายในการเดินทางไปราชการในราชอาณาจักร ตามคู่มือการเบิกค่าใช้จ่ายในการเดินทางไปราชการในประเทศ สำนักบริหารกลาง ส.ป.ก. (มี.ค. 2564) และระเบียบกระทรวงการคลังฯ ที่ใช้บังคับปัจจุบัน

## เอกสารที่จัดทำได้
- ใบเบิกค่าใช้จ่ายในการเดินทางไปราชการ แบบ 8708 ส่วนที่ 1 (2 หน้า)
- หลักฐานการจ่ายเงินค่าใช้จ่ายในการเดินทางไปราชการ แบบ 8708 ส่วนที่ 2
- ใบรับรองแทนใบเสร็จรับเงิน แบบ บก. 4231
- ใบสรุปการคำนวณ (เอกสารช่วยตรวจทานภายใน ไม่ใช่แบบตามระเบียบ)

## การใช้งาน
- เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้ทันที หรือเปิดผ่าน GitHub Pages
- ข้อมูลเก็บในเบราว์เซอร์ของเครื่องที่ใช้งาน (localStorage) ไม่มีการส่งข้อมูลออกนอกเครื่อง
- สำรอง/นำเข้าข้อมูลได้ด้วยไฟล์ JSON จากเมนูตั้งค่า
- พิมพ์ลงกระดาษ A4 ได้โดยตรง

## ข้อเสนอแนะเพิ่มเติม
